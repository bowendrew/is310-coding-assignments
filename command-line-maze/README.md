# Esports Cultural Data Maze
## Drew Bowen

Welcome to my Esports Cultural Data Maze!

This maze explores esports culture through games, players, tournaments, fans, and the different types of data they generate.

## Instructions

Begin your journey in the `entrance` directory.

Use command-line commands to navigate through the directories and read the clues.

Helpful commands:

- `ls` - list files and directories
- `cd` - move into a directory
- `cd ..` - move back one directory
- `cat` - read the contents of a file
- `ls -a` - show all files, including hidden files

Follow the clues until you find the championship and complete the maze.

Good luck!
