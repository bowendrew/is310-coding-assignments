### Web Technologies

I inspected Databallr using Chrome Developer Tools, where I found that the
website uses JavaScript and CSS. In the Sources tab, most of the files I
found ended in `.js`, which shows that JavaScript is mostly used by
the website for all of their statistics. I also found a `.css` file at the end, 
which is used to control the overall appearance of the webpage.

I didn't see any individual `.html` files listed in the Sources tab.
However, the website still uses HTML to structure the webpage, which can
be seen through the HTML elements displayed in the Elements tab.
